Settings

Make the timer work your way.

Timer

Hold to ready
How long Space must be held before the timer is ready.
Hold Space until the timer turns green, then release to start.
Show timer side stats
Show previous solve and averages beside the timer.
Hiding this gives the timer more room.
Running display precision
Digits shown while the timer is running.
This affects the live timer display only.
Final time precision
Digits shown for completed solves.
Stored times keep millisecond precision; this only changes formatting.
Prevent accidental restart
Ignore a Space press immediately after stopping.
Adds a short 250 ms pause after a solve.
Disable other keys while running
Keep keyboard shortcuts from interfering with a solve.
Space and Escape remain available while the timer runs.
Touch timer
Use touch and release on the time display to control the timer.
Touch mode uses the same hold-to-ready behavior as Space.

Manual time entry

Enable manual entry
Record times from a Stackmat or another timer.
Enable this to show the TYPE button and keyboard shortcut.
Manual entry hotkey
Single key that opens the manual time dialog.
Default: T. The shortcut is ignored while typing in a field.

Inspection

Inspection countdown
Start inspection with the first Space press.
Press Space once to inspect, then press and release Space to start the timer.
Inspection duration
Time before a +2 penalty begins.
After this time, the pending penalty changes to +2.
Overtime grace
Grace after inspection before the penalty becomes DNF.
At or after duration plus grace, the next solve is recorded as DNF.

Scramble

Show scramble
Display the scramble above the timer.
Hide the scramble panel when you do not need it.
Wrap scramble text
Allow long scrambles to wrap onto more than one line.
Turn off wrapping to keep the scramble on one line.
Monospace scramble
Use a fixed-width font for scramble moves.
Monospace fonts align move notation consistently.
Generate after solve
Automatically show a new scramble after timing a solve.
Turn this off to keep the current scramble until you request another.
Scramble length
Use each puzzle’s usual length or the custom move count below.
Length settings apply to move based puzzles; Clock and Megaminx use structured generators.
Hide scramble while timing
Keep the scramble out of view once a solve starts.
The scramble returns after the timer stops.
Manual scramble advance
Only generate a new scramble when you click “new”.
When enabled, automatic scramble advance is disabled.
Move count
Length for move-based scramble events.
This custom length applies to move-based puzzle scrambles.
MultiBLD scramble count
How many 3×3 scrambles to show for MultiBLD.
MultiBLD displays one generated 3×3 scramble per row.
Megaminx lines
Number of lines in the Megaminx display.
Megaminx uses a structured display; these settings control its layout.
Megaminx pairs per line
Number of R/D move pairs per line.
This changes only the generated Megaminx scramble layout.
Copy format
Choose what the scramble copy action copies.
The label option prefixes the copied text with the current puzzle name.

Solves and stats

Personal best feedback
Choose whether new PBs use a color flash.
PB comparison uses the selected scope below.
PB comparison scope
Choose which solves count when finding a PB.
The statistics panel remains scoped to the current session.

Show Ao12

Ao12 uses WCA-style trimming of the best and worst solve.

Stats precision
Digits used for averages and best times.
Changing display precision does not alter stored solve times.

Archived sessions are hidden until this option is enabled again.
